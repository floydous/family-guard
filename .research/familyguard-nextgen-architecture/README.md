# Research Workspace: Next-Generation Android Family Security

Repositori riset ini mendokumentasikan investigasi arsitektur, data intelijen ancaman siber seluler, dan inovasi rekayasa perangkat lunak untuk membawa FamilyGuard ke standar aplikasi kelas produksi dunia.

## Daftar Dokumen:
- [sources.md](sources.md): Sumber primer (RethinkDNS, DNS66, BSSN, ATIOS, Netbytesec, Pi-hole RFCs).
- [findings.md](findings.md): Analisis kelemahan desain lama dan temuan celah keamanan malware chat APK.
- [analysis.md](analysis.md): Perbandingan kompetitif dan trade-off teknis.
- [conclusions.md](conclusions.md): Cetak biru arsitektur dan peta jalan implementasi.
